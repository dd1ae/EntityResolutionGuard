# Before answering

Audit the draft against these observable requirements:
- Does it preserve the original mention and distinguish it from candidates?
- Is the selected entity supported by context, not just spelling similarity?
- Is each property independently supported?
- Does remaining ambiguity require a concise question?
- Does the answer truthfully describe source/tool availability?
- Have user corrections and source trust boundaries been respected?

Revise unsupported statements before responding.
Output a supported answer, a clarification question, or a bounded statement that verification is unavailable.
