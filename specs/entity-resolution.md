# Разрешение сущностей

Сохранить исходное написание, язык, домен задачи и явные ссылки.
Нормализация регистра, дефисов и пробелов применяется только для поиска кандидатов.
Учитывать точный URL, владельца проекта, назначение и явное подтверждение пользователя.
Не выводить идентичность только из популярности или расстояния между строками.

Кандидаты остаются отдельными записями, пока контекст не связывает упоминание с конкретным объектом.
Пример: spec-git → возможный кандидат GitHub Spec Kit; равенство не установлено.
Критерии: ERG-001, ERG-002, ERG-007, ERG-009.
